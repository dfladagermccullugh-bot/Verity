# Qualtrics fixtures

Files exported from the Qualtrics test survey described in
[`../../docs/qualtrics-test-survey.md`](../../docs/qualtrics-test-survey.md).

Only made-up answers belong here. Never a real respondent's data.

Expected once the Phase 0 check is done:

| File | What it is |
|---|---|
| `library-test.qsf` | The survey definition, exported from Qualtrics |
| `library-test-numeric.csv` | Response export, numeric values |
| `library-test-labels.csv` | Response export, choice text |
| `import-template.csv` | Qualtrics' own import example, if it offers one |
| `NOTES.md` | What the import attempt did, with any error text |
